## ⏱ 시간 추적 (이 이슈에 기록 — GitLab 전용)

- **착수 시**: 댓글에 `/estimate 1d 4h` 입력 (예상 소요, 1회).
- **진행 중**: 댓글에 `/spend 3h` 누적 입력 (실제 투입). 정정은 `/spend -1h`.
- 시간은 **이 이슈에만** 기록한다. PR/MR 에 적으면 합산되지 않는다.
